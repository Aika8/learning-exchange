# M3 demo — the game vertical slice («Летопись Ветров» 3D)

One game day in `game3d/` against the live exchange: Act I in short, Mara's plan with the 1% rule and the Anchor
(stop-loss), trading on the Ladder (spread, fees), a voyage that runs the exchange clock ×60 through a storm, the thin
market of Silk Reach (liquidity), the Forge report season with the Anchor gapped through, the evening chronicle from
computed `SessionFacts` and its replay. ADR-0023 (Accepted); decisions in `DECISIONS.md` → M3. No contract change.

## Run
```
make dev            # exchange + bots
make assets         # once: CC0 art (git-ignored)
make game3d
```
Keys: WASD, mouse, E — interact, G — the captain's glossary, Enter — close a lesson card, Tab — fly, F3 — fps.
Self-run demo that made the screenshots (fresh exchange on another port, in-memory journal; ≈ 40 minutes because it
waits for the Forge seasons at ×60):
```
make dev PORT=8090 JOURNAL=memory
cd game3d && godot --path . --resolution 1920x1080 --always-on-top -- --server=http://localhost:8090 --demo=../docs/demo/m3 --name=Aika
```
Apple M5, 1920×1080, Forward+/Metal, FSR 2 at 0.8. The fps is in the top-left corner of each shot.

## 6. The Forge report season
Ольва Перо publishes the consensus; the stock halts at night; the report comes out; it opens with a gap. The captain
bought FORGE with an Anchor before a bad season: in the run season 4 (EPS 1.11 vs consensus 2.20, −49.5%) opened
−24.5%: the Anchor at 404.78, the market at 315.77 — the stop-limit was skipped and hangs out of the market (see the

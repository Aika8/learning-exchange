# LE-013: determinism rules miss other clock and random sources

Found in review of LE-013. The `engine..` rules in `app.arch.EngineDeterminismTest` do not cover `ZonedDateTime.now`,
`OffsetDateTime.now`, `LocalTime.now`, `Year.now`, `Math.random`, `ThreadLocalRandom`, `SecureRandom` or
`UUID.randomUUID`. None is in the task's list, but each breaks determinism the same way. Suggested fix: a follow-up
task that adds them (the `owner + name("now")` pattern already in the test fits).

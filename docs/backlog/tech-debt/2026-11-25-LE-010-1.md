# LE-010: the engine-vs-reference comparison lives in three places

Found while doing LE-010. `DifferentialTest.compare` (LE-008) and `DifferentialDepthTest.compare` (LE-009) each walk
the actions through both books and `fail()` on the first difference; LE-010 needed the same walk as a value for the
shrinker and added `engine.model.Divergence.first(actions)` (ids, cancel results, trades, full depth).

Suggested fix (small, test-only): let both differential tests call `Divergence.first` and keep only their own
extras (seed in the message, depth-10 view, the "cancel the last id" probe), and on a failure print
`Shrinker.regressionFile(actions)` so the shrunk case can be saved straight into `src/test/resources/regressions/`.
Not done in LE-010 because it changes existing tests.
